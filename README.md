# 🫧 箱庭世界 · 3D 史莱姆

一个基于 **Three.js** 的微缩箱庭（Hakoniwa）世界，主角是一只果冻质感的 3D 史莱姆。
无需构建、无外部资源文件（模型与音效全部程序化生成），打开网页即可玩。

## 🎮 交互方式

| 操作 | 效果 |
| --- | --- |
| 🖐️ 按住史莱姆拖动 | 被拎起来悬浮跟随，身体拉出果冻滞后感，甩出去会落地弹跳 |
| 👆 快速点一下史莱姆 | 戳一戳：惊讶的 "o" 型嘴 + 弹跳 + 星星粒子 + "啵"声 |
| 🎯 点击地面任意位置 | 史莱姆一跳一跳地蹦过去（距离越远跳数越多） |
| 🔄 拖动空白处 | 旋转视角（OrbitControls） |
| 🔍 滚轮 / 双指 | 缩放视角 |
| 👀 移动鼠标 | 史莱姆瞳孔会盯着你看，还会随机眨眼 |
| 🔊 右上角按钮 | 开关音效 |

史莱姆还有**呼吸**、**落地挤压变扁（squash & stretch）**、**顶点级果冻抖动**等细节动画，
所有音效均由 Web Audio 实时合成，无任何音频文件。

## 🚀 运行方法

三种方式任选：

1. **直接打开**：双击 `index.html`（需联网加载 Three.js CDN）。
2. **本地服务器**（推荐）：
   ```bash
   python3 -m http.server 8000
   # 浏览器访问 http://localhost:8000
   ```
3. **GitHub Pages**：把仓库推到 GitHub 后，`Settings → Pages → Deploy from a branch`
   选择 `main` 分支 / 根目录，几分钟后访问
   `https://<用户名>.github.io/<仓库名>/` 即可在线游玩。

## 🛠️ 技术要点（作业可写进文档）

- **Three.js r170**（ES Module + importmap 引入 CDN，零构建）
- **果冻材质**：`MeshPhysicalMaterial` 的 `transmission / thickness / attenuation`
  实现半透明折射；`RoomEnvironment` 提供环境反射高光。
- **顶点级动画**：保留球体原始顶点/法线，每帧叠加两个**弹簧-阻尼衰减的正弦抖动模态**，
  再按高度的平方加入"滞后倾斜"，得到软软的手感。
- **挤压拉伸（Squash & Stretch）**：动画十二原则的经典手法，用一根欠阻尼弹簧驱动
  非等比缩放，落地压扁、起跳拉长。
- **拾取与拖拽**：`Raycaster` + 包围球命中判定 + 平面求交得到拖拽目标点；
  用捕获阶段事件阻止 OrbitControls 抢事件，实现"拖史莱姆 ≠ 转视角"。
- **状态机**：`free（物理弹跳）/ grab（弹簧跟随）/ hop（抛物线连跳）` 三态切换。
- **程序化音效**：Web Audio `OscillatorNode` 频率斜坡合成 "boing" 弹簧声。
- **场景全部程序化建模**：树木、小屋、池塘、石头、小花、云均为低多边形组合体，
  固定随机种子保证每次打开布局一致。
