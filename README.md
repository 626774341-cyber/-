# 夜贼 THE BURGLAR · 黑白等距潜入

纯黑白、纪念碑谷式等距立体的潜入偷窃游戏。你扮演礼帽绅士，
潜入豪宅的五间密室，偷光财宝并从出口脱身——别被看见。

## 怎么玩

- 双击 `index.html` 即可游玩（无需服务器）；或访问 http://127.0.0.1:52499/
- **WASD / 方向键**：移动　**Shift**：潜行
- **按住空格**：偷窃（蓄力环转满才得手；偷窃有声响，附近的守卫会察觉）
- 唱机旁按**空格**：声东击西——守卫会赶去查看（每台冷却 10 秒）
- **R** 重开本关　**P** 暂停　**M** 静音　标题画面 **1–5** 直达对应关卡

规则：
- 守卫的白色灯光扫到你会积累怀疑（头顶进度条+视线虚线），攒满即追捕，被碰到就被抓
- **灯光内圈与一切亮处极度危险**：走进光圈陷阱、站在亮着的台灯下，会被直接暴露、守卫直奔而来
- 开台灯能照亮一片区域，但开灯瞬间也会暴露位置——看得清与安全不可兼得
- 站进**黑色暗影**几乎隐形；守卫靠近时会有第五人格式的心跳声（越近越快越响）
- 偷光所有宝物后 EXIT 亮起，走上门即过关；3 条命，最高分本地保存

## 大地图

世界是原先的 1.9 倍，镜头平滑跟随主角，右上角有实时小地图
（白点=宝物，方块=唱机，箭头=守卫及其朝向，闪烁圆点=你）。
挡住主角的墙体与高家具会自动半透明，不会遮挡视线。

## 文件

- `index.html` —— 游戏本体（单文件，Canvas 2D 等距渲染）
- `assets/` —— 统一转为纯黑/纯白 + 透明底的 PNG 素材
- `prep_assets.py` —— 素材预处理脚本（Pillow）
- `contact_sheet.png` —— 素材处理一览表

## 调试参数

- `index.html?lv=N`：进入第 N 关（0–4）
- `&nearexit=1`：出生在出口处；游戏内按 `g` 直接开锁
