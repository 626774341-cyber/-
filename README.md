# 🫧 箱庭世界 · 3D 史莱姆（互动加强版）

一个基于 **Three.js** 的微缩箱庭（Hakoniwa）世界，主角是一只果冻质感的 3D 史莱姆。
无需构建、无外部资源文件（模型与音效全部程序化生成），打开网页即可玩。

## 🎮 交互方式一览

## 🚀 运行方法

三种方式任选：

1. **直接打开**：双击 `index.html`（需联网加载 Three.js CDN）。
2. **本地服务器**（推荐）：
   ```bash
   python3 -m http.server 8000
   # 浏览器访问 http://localhost:8000
   ```
3. **GitHub Pages**：把仓库推到 GitHub 后，`Settings → Pages → Deploy from a branch`
   选择 `main` 分支 / 根目录，几分钟后访问
   `https://<用户名>.github.io/<仓库名>/` 即可在线游玩。

## 🛠️ 技术要点（作业可写进文档）

- **Three.js r170**（ES Module + importmap 引入 CDN，零构建）
- **果冻材质**：`MeshPhysicalMaterial` 的 `transmission / thickness / attenuation`
  实现半透明折射；`RoomEnvironment` 提供环境反射高光；换色时同步改
  `color` 与 `attenuationColor`，彩虹模式每帧 `setHSL` 流光。
- **顶点级动画**：保留球体原始顶点/法线，每帧叠加两个**弹簧-阻尼衰减的正弦抖动模态**，
  再按高度的平方加入"滞后倾斜"，得到软软的手感。
- **挤压拉伸（Squash & Stretch）**：动画十二原则的经典手法，用一根欠阻尼弹簧驱动
  非等比缩放，落地压扁、起跳拉长。
- **拾取与拖拽**：`Raycaster` + 包围球命中判定（妈妈 > 宝宝 > 苹果 > 蝴蝶的优先级）
  + 平面求交得到拖拽目标点；用捕获阶段事件阻止 OrbitControls 抢事件。
- **交互状态机**：一次按住史莱姆的 gestures 按"位移 > 7px → 拖拽、
  时长 > 420ms → 抚摸、快速抬起 → 戳一戳"三路消歧，互不冲突。
- **实体系统**：史莱姆 / 宝宝 / 苹果 / 蝴蝶都是带 `free / grab / hop` 状态的小实体，
  宝宝用"领队链"跟随算法（朝领队后方 0.95m 的目标点周期性起跳）。
- **心情数值驱动表情**：单一数值 `mood.happy` 同时驱动嘴型（微笑/苦瓜脸）、
  眼睛（眯眯眼）、待机行为（小跳/叹气）与 UI 心情条——数值即人设。
- **昼夜系统**：一个 0→1 的过渡因子同时插值天空/雾色、太阳/月光强度、
  环境反射强度、窗户自发光、星星与萤火虫透明度，过渡丝滑无跳变。
- **程序化音效**：Web Audio `OscillatorNode` 频率斜坡合成 "boing"、白噪声 + 带通滤波
  合成水花声；静音保活振荡器让页面在后台标签页中不被强节流。
- **粒子对象池**：星星碎屑 / 爱心（`ExtrudeGeometry` 挤出）/ 音符与 Zzz（Canvas 精灵）
  / 波纹全部对象池复用，零 GC 压力。
- **场景全部程序化建模**：树木、小屋、池塘、石头、小花、云均为低多边形组合体，
  固定随机种子保证每次打开布局一致。
