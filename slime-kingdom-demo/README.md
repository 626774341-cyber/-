# 《盐与光 · 记忆之形》可玩 DEMO

第六组 · SLIME KINGDOM: The Shape of Memory 的单文件网页原型。
**双击 `index.html` 即可在浏览器游玩**,无需安装任何东西(Chrome/Edge/Safari 均可)。

## 一句话流程(约 15-25 分钟)

盐灯旁接任务 → 大厅收集 5 撮盐晶 → 液态(按 2)穿格栅取档案残页 →
北库击败「档案员之殇」吸收机关记忆 → 开内门 → 硬固态(按 3)按 B 架 3 块桥板 →
用固定剂修复档案架 → 档案馆重新亮起(通关)。

## 操作

| 按键 | 功能 |
|---|---|
| WASD / 方向键 | 移动 |
| 鼠标 | 瞄准(软弹朝准星发射) |
| Shift | 冲刺(消耗凝胶,带无敌帧) |
| Space | 凝胶态跳跃(跨低矮障碍)/ 液态滑行 |
| 1 / 2 / 3 | 凝胶态 / 液态(穿格栅、水中加速)/ 硬固态(建造、减伤 40%) |
| 左键 | 软弹(6 凝胶);学会剑术后近战自动三连击 |
| E | 互动:对话 / 拾取 / 吸收记忆残响 / 开门 / 修复 / 盐灯休息 |
| B | 建造模式(硬固态专属,断桥处放置桥板) |
| C | 制作(固定剂 = 盐×3 + 凝胶团×2) |
| Tab / J | 背包 / 任务日志 |
| F5 / F9 | 存档 / 读档(盐灯休息=自动存档) |
| M | 静音 |
| Esc | 暂停菜单 |

## 系统对应(开发规格书 T0–T16)

- ✅ 三形态状态机 + 凝胶资源(移动/战斗/建造三合一)
- ✅ 对话系统(逐字打印、分支选项、剧情命令)
- ✅ 任务系统(三条主线任务链、步骤追踪、自动推进)
- ✅ 吸收记忆 → 技能(守卫的剑术 / 档案员的机关术=钥匙)
- ✅ 战斗(软弹抛物线 / 三段近战 / 敌人三态 AI / 精英冲锋)
- ✅ 昼夜潮汐(90 秒一天;夜间涨潮淹没低洼,液态专用路线)
- ✅ 建造(网格吸附桥板,潮汐后保留,计入存档)
- ✅ 存档(3 项内容全量序列化 + 自动存档)
- ✅ 音频(WebAudio 实时合成 BGM/SFX,昼夜自动切换氛围)
- ✅ 通关结算画面

## 已知边界(有意简化)

- 美术为占位色块(正式素材由 Giulio 的美术基调替换,文件名不变)
- 背包/任务为只读面板;商店、快速旅行、好感度未开放(P1)
- **背景音乐为组内主题曲《盐与歌》(豆包 AI 生成,`bgm.m4a`),白天/夜晚自动调节音量,M 键静音**;音效为 WebAudio 实时合成

> 注意:`index.html` 与 `bgm.m4a` 需放在同一目录;直接双击本地打开即可,若浏览器拦截本地音频,可用
> `python3 -m http.server` 起个本地服务访问。
